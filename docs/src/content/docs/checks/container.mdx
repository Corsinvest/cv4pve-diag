Checks run on every LXC container. Several codes are shared with VMs and mean the same thing there. How to read the codes: [Overview](/cv4pve-diag/checks/).

## State and configuration

| Code | SubContext | Gravity | Description |
|---|---|---|---|
| `IG0010` | Status | <Severity level="Info" /> | Config changes pending reboot to take effect |
| `WG0015` | Status | <Severity level="Warning" /> | Container is locked and cannot be managed |
| `WG0041` | Config | <Severity level="Warning" /> | Container has raw LXC config entries that bypass PVE abstractions |
| `IG0014` | Config | <Severity level="Info" /> | Container has no hostname configured |
| `WG0016` | StartOnBoot | <Severity level="Warning" /> | CT will not start automatically after host reboot |
| `IG0011` | Protection | <Severity level="Info" /> | CT protection flag not set |
| `WG0018` | Hardware | <Severity level="Warning" /> | Disk detached from CT but still in storage |

## Security and features

| Code | SubContext | Gravity | Description |
|---|---|---|---|
| `WG0039` | Security | <Severity level="Warning" /> | Container runs as privileged — root inside has host-level access |
| `CG0006` | Security | <Severity level="Critical" /> | Privileged container has AppArmor disabled — no kernel confinement |
| `IG0017` | Features | <Severity level="Info" /> | Unprivileged container with `nesting=1` but no `keyctl=1` — Docker/systemd may not work (replaces `WG0038`) |

## Backup and snapshots

| Code | SubContext | Gravity | Description |
|---|---|---|---|
| `WG0017` | Backup | <Severity level="Warning" /> | CT not included in any backup job |
| `CG0002` | Backup | <Severity level="Critical" /> | A disk has backup disabled |
| `WG0019` | Backup | <Severity level="Warning" /> | Backup files older than configured days found (protected excluded) |
| `WG0020` | Backup | <Severity level="Warning" /> | No backup found in the last configured days |
| `WG0021` | AutoSnapshot | <Severity level="Warning" /> | cv4pve-autosnap not configured |
| `WG0022` | AutoSnapshot | <Severity level="Warning" /> | Old AutoSnap snapshots present — update required |
| `WG0023` | SnapshotOld | <Severity level="Warning" /> | Snapshots older than configured age |
| `WG0035` | Snapshot | <Severity level="Warning" /> | Snapshot includes RAM state — wastes disk space and blocks storage migration |
| `WG0024` | SnapshotCount | <Severity level="Warning" /> | Snapshot count exceeds configured limit |

## High availability

| Code | SubContext | Gravity | Description |
|---|---|---|---|
| `CG0005` | HA | <Severity level="Critical" /> | Disk on non-shared storage, CT managed by HA and not replicated — migration will fail |
| `IG0015` | HA | <Severity level="Info" /> | Running container not managed by HA while other guests are — will not be restarted on node failure |
| `WG0043` | Replication | <Severity level="Warning" /> | HA container with disks on local storage has no enabled replication job — failover target will have no recent data |

## Network and firewall

| Code | SubContext | Gravity | Description |
|---|---|---|---|
| `WG0033` | Network | <Severity level="Warning" /> | MAC address shared with another VM/CT or interface — causes network conflicts |
| `WG0013` | Firewall | <Severity level="Warning" /> | Container firewall is disabled — exposed to all bridge traffic |
| `IG0009` | Firewall | <Severity level="Info" /> | Container can spoof source IP addresses |

## Tasks and resource usage

| Code | SubContext | Gravity | Description |
|---|---|---|---|
| `WG0040` | Memory | <Severity level="Warning" /> | Container has no memory limit (Memory=0) — can consume all host RAM |
| `IG0013` | Memory | <Severity level="Info" /> | Container has swap disabled — OOM killer risk under memory pressure |
| `CG0003` | Tasks | <Severity level="Critical" /> | Failed tasks found in the last 48 hours |
| `WG0025`/`CG0025` | Usage | <Severity level="Warning/Critical" /> | CPU usage above configured threshold |
| `WG0026`/`CG0026` | Usage | <Severity level="Warning/Critical" /> | Memory usage above configured threshold |
| `WG0027`/`CG0027`, `WG0028`/`CG0028` | Usage | <Severity level="Warning/Critical" /> | Network throughput above configured threshold |
| `WG0029`/`CG0029` | Pressure | <Severity level="Warning/Critical" /> | Linux PSI CPU pressure above threshold (PVE 9.0+) |
| `WG0030`/`CG0030` | Pressure | <Severity level="Warning/Critical" /> | Linux PSI I/O full pressure above threshold (PVE 9.0+) |
| `WG0031`/`CG0031` | Pressure | <Severity level="Warning/Critical" /> | Linux PSI memory full pressure above threshold (PVE 9.0+) |
| `WG0032`/`CG0032` | HealthScore | <Severity level="Warning/Critical" /> | Composite health score below threshold |

Any of these can be hidden with an [ignore rule](/cv4pve-diag/ignored-issues/) on its code.

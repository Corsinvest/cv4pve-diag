cv4pve-diag talks to the Proxmox VE REST API of any node of the cluster. Create the user and API token
first — see [Permissions](/cv4pve-diag/permissions/).

## Options in a file

A health check run by cron or Task Scheduler repeats the same connection every time: keep it in a file.

<CliResponseFiles
  tool="cv4pve-diag"
  user="diag@pve"
  token="audit"
  extra={[
    '# Your own thresholds and accepted findings, see Settings and Ignore rules',
    '# --settings-file=/etc/cv4pve/diag-settings.json',
    '# --ignored-issues-file=/etc/cv4pve/ignored-issues.json',
  ]}
  run="execute"
/>

`--settings-file` and `--ignored-issues-file` go before `execute`, so they can live in the same file as
the connection.
